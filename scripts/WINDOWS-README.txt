SocketAgent Desktop - development preview

Extract the ENTIRE ZIP into a folder of your choice.
Run socketagent.exe to use it from that folder.
To add Start menu and Desktop shortcuts, run install-windows-app.cmd.
The optional installer copies the app to %LOCALAPPDATA%\SocketAgentDesktop.
It does not install or change the SocketAgent server.

A running server installed for your Windows user is detected automatically.
Use Settings > Computers to add remote computers or import credentials.
On Android, export your computers, save the QR image, then open that image
in Import computers on Windows. Enter the same transfer passphrase.
You can also paste the transfer text. Camera scanning is not included yet.

The custom title bar supports dragging, double-click to maximize, and edge resizing.
Its controls open the app menu, minimize, maximize/restore, and hide to the tray.
Closing the window or pressing Alt-F4 also hides to the tray. Open the tray icon
or launch the shortcut to restore the same running window. Choose Quit SocketAgent Desktop
from the app menu or tray menu to exit. The server continues running independently.
Window size, position, and maximized state are remembered after quitting.
Desktop notifications are event alerts, without ongoing work or download progress.
This preview does not have automatic updates or Windows code signing yet.
